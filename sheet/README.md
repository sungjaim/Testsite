# 구글 시트로 드레스 관리하기

드레스 정보를 구글 시트에서 고치면 사이트에 반영돼요. 시트 한 줄이 드레스 한 벌이에요.

## 한 번만 하는 준비

### 1. 시트 만들기
1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 만들어요.
2. **파일 → 가져오기 → 업로드**에서 이 폴더의 `dresses-template.csv`를 올려요.
3. 가져오기 위치는 **현재 시트 바꾸기**를 골라요. 지금 사이트에 있는 드레스 6벌이 채워져요.

### 2. 칸마다 드롭다운 만들기 (오타 방지)
- **상태 칸:** F열 전체를 선택하고, **데이터 → 데이터 확인(유효성 검사) → 규칙 추가 → 드롭다운**으로 고른 뒤 항목에 `대여 가능`, `준비 중`을 넣어요.
- **홈 슬라이드 칸:** H열을 선택하고 **삽입 → 체크박스**를 눌러요. 체크가 켜진 드레스가 홈 화면 의상 레일의 맨 앞에 나와요.
- **색상 칸(선택):** 같은 방법으로 `블랙, 화이트, 핑크, 레드, 블루, 퍼플, 오렌지, 코랄, 옐로` 드롭다운을 만들면 좋아요.

### 3. 웹에 게시하기
1. **파일 → 공유 → 웹에 게시**를 눌러요.
2. 왼쪽을 **해당 시트(드레스 시트 이름)**, 오른쪽을 **쉼표로 구분된 값(.csv)**로 바꿔요.
3. **게시**를 누르고, 나오는 주소를 복사해요. `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`처럼 생겼어요.
4. 이 주소를 사이트 담당자(또는 Claude)에게 전달해요.

### 4. 사이트에 연결하기
`js/config.js`의 `window.LS_SHEET_URL = '';` 따옴표 안에 위 주소를 붙여 넣고 저장해요. 끝이에요.

## 열 설명 (첫 줄은 지우거나 바꾸지 마세요)
| 열 | 내용 | 비어 있으면 |
|---|---|---|
| 번호 | 01, 02 처럼. **사진 폴더 이름과 연결돼요** (`images/dresses/ls-01/`) | 이 줄은 무시돼요 |
| 이름 | 드레스 이름 | 이 줄은 무시돼요 |
| 사이즈 | 130, S 등 | "확인 필요"로 표시 |
| 색상 | 목록에 있는 색 이름. 새 색을 쓰면 그 글자 그대로 필터에 생겨요 | 색상 칸 없음 |
| 대여료 | 숫자만. 예: 80000 | "확인 필요"로 표시 |
| 상태 | 대여 가능 / 준비 중 (세탁·점검·수선 등으로 잠시 대여를 쉴 때 준비 중) | **준비 중**으로 표시 |
| 사진 수 | 올려 둔 사진 장수 (1.jpg, 2.jpg... ) | 1장으로 봐요 |
| 홈 슬라이드 | 체크하면 홈 화면 의상 레일의 맨 앞에 나와요 | 나머지 자리에 고르게 섞여 나와요 |
| 종류 | '남자 의상'이라고 쓰면 목록의 **남자 의상** 탭에만 나와요 | 드레스 탭에 나와요 |

## 예약과 대회 (다른 탭)

시트에는 탭이 3개 있어요. **세 탭 모두 웹에 게시**해야 해요.

| 탭 | 내용 |
|---|---|
| **드레스** | 드레스 한 벌이 한 줄 (위 표) |
| **예약** | **자동.** '2026 정산' 시트에서 의상 번호와 대회 날짜만 가져와요. 직접 적지 마세요. |
| **대회** | 지금은 쓰지 않아요 ('다가오는 대회' 버튼을 없앴어요) |

### 예약은 정산 시트에만 적어요
- 누나는 지금처럼 **'2026 정산'** 시트(1분기~4분기 탭)에 예약을 적으면 돼요. 사이트가 그중 **대회일자(A열)와 의상번호(D열)** 만 가져가요. 손님 이름·연락처는 정산 시트에만 남고 사이트에는 나오지 않아요.
- "예약" 탭의 A2 칸에 가져오는 수식이 들어 있어요. 이 칸을 지우거나 고치지 마세요.
- **의상번호는 숫자로** 적어 주세요. `71번`, `71`, `69번,49번`, `5/7번`은 알아봐요. `신규 보라`, `핑크드레스`처럼 번호가 없으면 사이트에서 막히지 않아요.
- **대회일자는 연도까지** 적어 주세요. `2026. 5. 16` 처럼요.
- 사이트는 공연일 **앞 8일 ~ 뒤 5일**을 "예약 불가"로 막아요. 예약이 취소되면 정산 시트에서 그 줄의 의상번호를 지우거나 "취소"라고 고쳐 주세요.
- **새해가 되면:** '2027 정산' 시트를 만들면 "예약" 탭 A2 수식 속의 시트 주소(id)를 새 시트 것으로 바꿔야 해요. 탭 이름(1분기~4분기)과 칸 위치(A열 날짜, D열 의상번호, 3행부터)는 지금과 같게 해 주세요.
- 처음 연결할 때 한 번, "예약" 탭 A2 칸을 누르고 **액세스 허용**을 눌러야 해요.

- **날짜 칸:** 날짜는 `2026-12-20`처럼 연도까지 써요. 시트가 날짜로 알아보면 `2026. 12. 20`처럼 바뀌어 보여도 괜찮아요.
- **절대 넣으면 안 되는 것:** 게시된 탭은 누구나 볼 수 있어요. **손님 이름, 연락처, 계좌 같은 정보는 이 시트에 적지 마세요.** "메모" 칸에도요. 손님 정보는 게시하지 않는 별도 파일에 따로 적어 주세요.

## 알아두세요
- **반영 시간:** 구글이 게시된 시트를 몇 분 동안 보관해서, 시트를 고친 뒤 사이트에 보이기까지 보통 몇 분 걸려요. 급하면 시트의 **웹에 게시 → 게시 중단 → 다시 게시**를 하면 빨라질 수 있어요.
- **공개 범위:** 게시한 시트는 주소를 아는 누구나 읽을 수 있어요. 손님 이름, 연락처 같은 개인정보는 **절대** 이 시트에 넣지 마세요. 고치는 건 시트 주인만 가능해요.
- **시트를 못 읽을 때:** 인터넷이나 구글 문제로 시트를 못 읽으면, 마지막으로 읽은 내용 또는 `data/dresses.js`의 내용이 대신 보여요. 시트를 고쳤는데 사이트가 그대로면 이 경우일 수 있어요.
- **시트 연결 중에는** `data/dresses.js`의 드레스 정보는 바뀌어도 화면에 반영되지 않아요 (시트가 우선). 색상 이름(`LS_COLORS`)과 상태 이름(`LS_STATUS`)만 계속 `data/dresses.js`에서 가져와요.
