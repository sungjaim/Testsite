# LS 피겨 드레스 대여 사이트

피겨 스케이팅 드레스 대여 카탈로그 사이트예요. 예약·결제 기능은 없고, 문의는 인스타그램 DM(@loveurskating)과 전화/문자(010-4342-8908)로만 받아요.

빌드 도구 없이 HTML, CSS, JavaScript 파일만으로 만들었어요. 파일을 고치고 올리면 그대로 사이트에 반영돼요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 홈 (슬라이드쇼, 서비스 장점) |
| `dresses.html` | 드레스 목록과 사이즈·색상 필터 |
| `dress.html` | 드레스 상세. 주소 끝의 `#ls-01`로 어떤 드레스인지 정해요 |
| `guide.html` | 대여 안내. **본문을 이 파일에서 직접 고쳐요** |
| `directions.html` | 오시는 길 (주소, 지도, 지도 앱 버튼). 주소가 바뀌면 이 파일과 `js/i18n.js`의 `footer.addr`를 고쳐요 |
| `data/dresses.js` | **드레스 목록. 드레스 추가·수정은 이 파일만 고치면 돼요** |
| `js/i18n.js` | 한국어/영어 문구 |
| `js/main.js` | 헤더, 메뉴, 푸터, 언어 전환. 연락처도 여기 있어요 |
| `css/style.css` | 디자인(색, 글꼴, 여백) |
| `images/` | 로고와 드레스 사진 |

## 드레스 추가하기

1. 사진을 `images/dresses/<id>/` 폴더에 `1.jpg`, `2.jpg` 순서로 올려요. `1.jpg`가 대표 사진이에요.
2. `data/dresses.js`를 열고, 드레스 한 덩어리 `{ ... },`를 복사해서 목록 끝에 붙여요.
3. 값을 바꿔요.

```js
{
  id: 'ls-07',              // 사진 폴더 이름과 같게
  number: '07',
  name: 'Swan Lake',
  size: '140',              // 모르면 null
  color: 'white',           // LS_COLORS 에 있는 키
  status: 'available',      // 'available' 대여 가능 / 'servicing' 준비 중
  booked: [],               // 예약이 잡힌 대회 이름. 예: ['예시 대회 A']
  price: 80000,             // 숫자만. 모르면 null
  photos: ['images/dresses/ls-07/1.jpg', 'images/dresses/ls-07/2.jpg'],
  featured: true            // 홈 슬라이드쇼에 넣으려면 true
},
```

- 필터 버튼은 드레스 데이터에서 자동으로 만들어져요. 새 사이즈나 색을 쓰면 버튼도 생겨요.
- 새 색상은 같은 파일 위쪽의 `LS_COLORS`에 한 줄 추가해요.
- 사진이 4장보다 적으면 상세 페이지의 남는 칸에 연회색 "사진 준비 중"이 표시돼요.
- **공개 전에 꼭:** 드레스의 사이즈·대여료와 대여 안내의 "확인 필요"를 실제 내용으로 채워 주세요.

## 드레스 상태와 대회별 예약

구글 시트를 연결해 두었다면 **시트에서 고쳐요** (방법은 `sheet/README.md`). 시트를 못 읽을 때를 대비한 예비 데이터는 `data/dresses.js`에 있어요.

**드레스 상태 (2가지)**

| 값 | 화면에 보이는 글자 | 뜻 |
|---|---|---|
| `'available'` | 대여 가능 | 빌려줄 수 있는 드레스 |
| `'servicing'` | 준비 중 | 세탁·점검·수선 등으로 잠시 대여를 쉬는 중 |

**대회별 예약**

- 대회마다 그 드레스가 **예약 가능**인지 **예약 마감**인지 보여요. A 대회에 예약이 있어도 B 대회는 따로 예약할 수 있어요.
- 손님이 공연 일자를 알려 주면 그 대회에 예약을 표시해요. (시트에서는 그 대회 칸에 체크)
- 날짜가 지난 대회는 사이트에서 자동으로 숨겨져요.
- 드레스 목록에서 "대회"를 고르면 그 대회에 예약 가능한 드레스만 보여요.
- 목록에 없는 대회나 공연은 "문의해 주세요"라고 안내돼요.
- `data/dresses.js`에서는 `LS_EVENTS`에 대회를 적고, 드레스의 `booked: ['대회 이름']`에 예약된 대회를 적어요.

## 사진 촬영 가이드

드레스가 사이트의 주인공이라, 모든 사진을 같은 조건으로 찍으면 목록이 훨씬 고급스러워 보여요.

| 항목 | 기준 |
|---|---|
| **비율** | 세로 4:5 (예: 2400×3000px). 사이트가 4:5로 보여 주므로, 다르게 찍으면 가장자리가 잘려요 |
| **해상도** | 원본은 짧은 변 2000px 이상. 올릴 때는 가로 1600px 정도, JPG 품질 80~85%, 한 장 400KB 이하로 줄여요 |
| **배경** | 무지 연회색 또는 흰색 벽·천. 주름, 그림자, 생활 소품이 안 보이게. **모든 드레스를 같은 배경에서** |
| **구도** | 마네킹을 가운데에 두고 위아래에 여백을 조금 남겨요. 카메라는 가슴 높이에서 정면으로 |
| **조명** | 흐린 날 창가의 자연광이나 부드러운 조명. 직사광선과 플래시는 피해요. 스톤은 빛을 비스듬히 주면 잘 반짝여요 |
| **색** | 실제 색과 같게. 필터나 과한 보정은 하지 않아요 |
| **로고** | 왼쪽 위 LS 워터마크는 모든 사진에서 같은 위치·크기로 |

**드레스당 추천 컷 (4~6장):**

1. 정면 전신 (대표 사진)
2. 뒷면 전신
3. 옆면 또는 비스듬히
4. 상체 장식 클로즈업 (스톤, 레이스)
5. 소매나 스커트 디테일
6. (선택) 착용 사진

파일 이름은 `1.jpg`, `2.jpg`... 처럼 숫자로, 위 순서대로 붙여요.

## 내 컴퓨터에서 미리 보기

이 폴더에서 아래 명령을 실행하고, 브라우저에서 http://localhost:8000 을 열어요.

```
python3 -m http.server 8000
```

## 무료로 배포하기 (GitHub Pages)

1. GitHub의 이 저장소에서 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치는 `main`, 폴더는 `/ (root)`로 정하고 저장해요.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 사이트가 열려요.
4. 이후에는 `main`에 올릴 때마다 자동으로 반영돼요.

나만의 주소(예: `lsdress.kr`)를 쓰고 싶으면 도메인을 사서(연 1~2만 원대) 같은 Pages 화면의 **Custom domain**에 넣으면 돼요. Cloudflare Pages도 같은 방식으로 무료로 쓸 수 있어요.

## 디자인 규칙

- 색은 흰색, 검정, 회색만 써요. 로고의 파랑·핑크는 로고에만 써요.
- 그라데이션, 진한 그림자, 이모지, 화려한 애니메이션은 쓰지 않아요.
- 제목은 명조(영문 Cormorant Garamond, 한글 Noto Serif KR), 본문은 Pretendard예요. 제목 글꼴은 `css/style.css`의 `--font-display`에서 바꿔요.
